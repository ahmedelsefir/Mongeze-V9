# قواعد مشروع مونجيز - ممنوع مخالفتها
1. ممنوع تماماً تعديل أو مسح أو لمس ملف.streamlit/secrets.toml
2. جميع المفاتيح تقرأ فقط من st.secrets["firebase"] - لا تكتب أي مفتاح في الكود
3. عند إضافة وظيفة جديدة، أضفها كدالة جديدة فقط، لا تغير الدوال القديمة الموجودة
4. حافظ على اسماء الـ collections الحالية: المياء، طلبات، عمليات التسليم
5. استخدم firebase_admin فقط
